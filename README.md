# Calculadora CLI Interativa
Implementação de uma calcladora em linha de comando, desenvolvida em Python. Reune as principais operações matemáticas, projetada para realizar cálculos contínuos. 

# Recursos utilizados:
* Python (linguagem de programação).

# Destaques técnicos:
* Laço de repetição (while): mantém a aplicação em execução, possibilitando que o usuário insira números e operadores continuamente, sem precisar reiniciar o programa. 
* Tratamento de exceções (try-except): assegurando a entrada de dados válidos.
* Conversão de tipos de dados: realizada de forma dinâmica nas entradas de texto para números decimais. 
* Estrutura de dados: utilização de listas para armazenar histórico de números e operadors durante a sessão. 

# Funcionalidades:
* Entrada iterativa de números com validação de dados. 
* Suporte a operações aritméticas principais (adição, subtração, multiplicação e divisão). 
* Feedback em tempo real: para cada cálculo efetuado no terminal. 

# Como executar o objeto localmente: siga os passos abaixo em seu terminal.
* Realize a instalação do Python em seu computador. 
* Clone este repositório do projeto.
* Iniciar a aplicação via terminal: python calculadora_cli.py
